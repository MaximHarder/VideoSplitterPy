# VideoSplitterPy

Это руководство про программу `videosplitter`, обычным языком. Команда — это пакет `videosplitter` в этом репозитории. Там, где план ещё не закрыт, страница следует последней версии плана.

Программа нужна, когда ролик слишком длинный или слишком тяжёлый для одного файла. Вы выбираете правило, оно называется профилем. Программа режет видео на части через FFmpeg. Картинка и звук копируются как есть, без перекодирования.

Одна и та же команда работает в Windows и в Unix (Linux и macOS).

## Что нужно заранее

- Python 3.11 или новее.
- FFmpeg на компьютере: программы `ffmpeg` и `ffprobe`. Путь лежит в настройках. Стартовое значение — имя `ffmpeg`, то есть «взять ту, что уже есть в PATH».
- Для подписи на кадре FFmpeg должен быть собран с фильтром `drawtext`, а файл шрифта из профиля должен существовать. Имя шрифта по умолчанию — Times New Roman. В Linux этого шрифта часто нет, пока его не установить.

Команда в консоли: `videosplitter`.

## Установка через uv

Установщик — uv. Отдельной команды `uv install` для этой программы нет.

Из папки репозитория, когда пакет уже будет в коде:

```text
uv tool install .
videosplitter -f movie.mp4
```

`uv tool install .` читает точку входа в `pyproject.toml` и кладёт `videosplitter` в PATH. Запись такая: `videosplitter = "videosplitter.cli:main"`.

Если оболочка не находит `videosplitter`, выполните `uv tool update-shell` и откройте терминал заново. Так папка инструментов uv попадает в PATH.

Из рабочей копии, без глобальной установки команды:

```text
uv run videosplitter -f movie.mp4
```

FFmpeg uv не ставит. Его нужно установить отдельно.

## Где лежат ваши файлы

Настройки не хранятся в папке, куда установлена программа.

- Windows: `%APPDATA%\videosplitter`
- Linux и macOS: `$XDG_CONFIG_HOME/videosplitter`, или `~/.config/videosplitter`, если переменная пустая

Внутри:

- `settings.yml` — настройки программы.
- `profiles/default.yml` — профиль, если вы не назвали другой.
- `profiles/<имя>.yml` — любой дополнительный профиль. Имя вы передаёте флагом `-p`.

Первый запуск создаёт эту папку, `settings.yml` и `profiles/default.yml`, если их ещё нет.

Отдельного флага «указать другую папку настроек» нет.

## Настройки

`settings.yml` действует на каждый запуск, пока флаг на одну команду не подменит отдельное поле.

| Настройка | Смысл | Старт |
| --- | --- | --- |
| Путь к FFmpeg | Чем резать видео и узнавать длительность | `ffmpeg` из PATH |
| Расширения | Какие файлы считать видео | `mp4`, `avi`, `flv`, `wmv`, `mkv` |
| Удалить исходник | Стереть оригинал после удачной нарезки | выкл |
| Временная папка | Куда часть пишется перед переносом на место | системная временная папка |
| Заменять существующее | Перезаписать файл, который уже лежит на выходе | выкл |
| Папка вывода | Куда класть готовые части | `{source_dir}` |
| Профиль по умолчанию | Какой профиль брать без `-p` | `default` |

`{source_dir}` — это подстановка, а не имя папки.

- Для одного файла это папка, в которой лежит файл.
- Для `--bulk` это папка, которую вы указали как источник.

Пример:

```yaml
ffmpeg: ffmpeg
extensions:
  - mp4
  - avi
  - flv
  - wmv
  - mkv
remove_source: false
temp_dir: ""
replace_existing: false
output_dir: "{source_dir}"
default_profile: default
```

Пустой `temp_dir` значит системную временную папку.

Регистр расширения не важен. `MP4` и `mp4` — одно и то же.

## Профили

Профиль — это один сохранённый способ нарезки. Файл: `profiles/<имя>.yml`.

Профиль `default` из поставки:

- нарезка по размеру
- предел 1800 МБ
- минимальная длина части 1 минута
- кадры выключены
- имя части `{video_name}_p{part|pad(2)}.{ext}`

Профилей может быть сколько угодно. Флаг вроде `--split-by` меняет профиль только на этот запуск и не переписывает YAML.

### Минимальная длина части

Если всё видео короче этой длины, программа его не режет. Частей нет, кадра нет, исходник не удаляется.

Старт — 1 минута. Ролик в 40 секунд остаётся как был.

Эта проверка отдельно от минимума в режиме «гибкое время».

### По размеру

Вы задаёте размер в мегабайтах. Программа считает:

`n = ceil(байты файла / (предел МБ × 1024 × 1024))`

- `n` равен 1 или меньше: не резать. Файл и так влезает в предел.
- `n` равен 2 или больше: `n` частей равной длительности. Последняя часть кончается ровно в конце ролика, время не теряется.

Пример: файл 3000 МБ и предел 1800 МБ дают `ceil(3000 / 1800) = 2`. Две части одинаковой длины.

Режется по времени, а не по счётчику байт каждой части. Если конец ролика «тяжелее», последний файл может выйти больше предела.

### По фиксированному времени

Вы задаёте, сколько минут может длиться одна часть.

- Если ролик влезает в один отрезок, он не режется.
- Иначе каждая часть равна этому числу минут, а последняя забирает остаток.

Остаток может быть короче минимальной длины части. Минимальная длина останавливает нарезку только когда короче весь ролик.

Пример: 50 минут, отрезок 30 минут. Получится 30 минут и затем 20.

### По гибкому времени

Вы задаёте минимум и максимум длины части в минутах.

- Если ролик короче минимальной длины части профиля (по умолчанию 1 минута), он не режется.
- Если ролик не длиннее гибкого максимума, он не режется: он и так одна часть.
- Иначе `n = ceil(длительность / максимум)`, и каждая часть равна `длительность / n`.
- Если общая длина всё ещё короче гибкого минимума, программа останавливается с ошибкой. Оба числа сразу выполнить нельзя.

Пример: 23 минуты, минимум 5, максимум 10. `ceil(23 / 10) = 3`, `23 / 3` — около 7,7 минуты. Все три части внутри 5–10.

Пример ошибки: 11 минут, минимум 8, максимум 10. Две части были бы по 5,5 минуты, это меньше 8. Одна часть была бы 11, это больше 10.

### По числу частей

Вы задаёте, сколько частей нужно. Число не меньше 1.

- `1` значит не резать.
- `2` и больше — столько частей равной длительности.

Пример: `--split-parts 4` на ролике в 40 минут даёт четыре части по 10 минут.

## Имена

Имя файла части берётся из шаблона. Метки стоят в фигурных скобках.

| Метка | Смысл |
| --- | --- |
| `{video_name}` | Имя исходного файла без расширения |
| `{file_name}` | Тот же корень имени. Нужна для подписи на кадре |
| `{ext}` | Расширение исходника без точки |
| `{part}` | Номер этой части, с 1 |
| `{parts}` | Сколько частей получилось у этого ролика |

В метку можно передать функцию: `{video_name|uppercase}`.

Функции для текста:

| Функция | Эффект |
| --- | --- |
| `translited` | Переписывает текст латиницей |
| `uppercase` | Заглавные буквы |
| `lowercase` | Строчные буквы |

Функции для чисел:

| Функция | Эффект |
| --- | --- |
| `pad(2)` | Минимум две цифры: `1` становится `01` |
| `int` | Целое число |
| `round(2)` | Две цифры после запятой |

Функции можно соединять: `{video_name|translited|lowercase}`.

Шаблон по умолчанию: `{video_name}_p{part|pad(2)}.{ext}`. Файл `Holiday.mp4`, разрезанный надвое, станет `Holiday_p01.mp4` и `Holiday_p02.mp4`.

В подписи на кадре блок `[is_final]...[/is_final]` остаётся только у последней части. У предыдущих текст между метками выкидывается. Шаблон подписи по умолчанию: `{part},[is_final][/is_final],{file_name}`. Если внутри меток пусто, у последней части всё равно остаются две запятые.

## Кадры

В профиле `default` кадры выключены. Включаются отдельно в каждом профиле.

```yaml
create_screenshot: false
screenshot_time: "50% of the part"
screenshot_name: "{video_name}_p{part|pad(2)}"
screenshot_format: jpg
write_label: false
label_template: "{part},[is_final][/is_final],{file_name}"
label_font: "Times New Roman"
label_size_px: 13
label_color: white
label_position:
  bottom: 15
  right: 5
label_border_px: 2
label_border_color: black
```

### Момент кадра

`screenshot_time` — одно из значений:

| Значение | Какой кадр |
| --- | --- |
| `first frame of the part` | Начало этой части |
| `last frame of the part` | Конец этой части |
| `random frame of the part` | Случайный момент внутри этой части |
| `50% of the part` | Середина этой части. Годится любой целый процент от 0 до 100. 0 — первый кадр, 100 — последний |
| `first frame of the video` | Начало исходного файла |
| `last frame of the video` | Конец исходного файла |
| `random frame of the video` | Случайный момент во всём ролике |
| `50% of the video` | Середина исходного файла. Снова от 0 до 100 |

Старт — `50% of the part`.

Процент меньше 0 или больше 100 — ошибка.

«Случайный» значит «от начала этого отрезка и до конца, не включая сам конец». В тестах момент задан заранее, чтобы результат не прыгал. В обычном запуске — нет.

### Имя и формат

`screenshot_name` использует те же метки, что и имя части. Старт — то же базовое имя, что у части, поэтому картинка лежит рядом и называется так же, без расширения видео.

`screenshot_format` — это `jpg`, `png` или `webp`. Старт — `jpg`. Расширение на диске берётся из формата, а не из `{ext}`.

Часть `Holiday_p01.mp4` при настройках по умолчанию получает рядом `Holiday_p01.jpg`.

### Подпись

`write_label` — да или нет. «Нет» оставляет кадр таким, каким его снял FFmpeg.

«Да» рисует подпись фильтром FFmpeg `drawtext`. Отдельной библиотеки для картинок нет.

- Шрифт: Times New Roman, если не заменить `label_font`.
- Размер: 13 px.
- Цвет: белый.
- Обводка: 2 px, чёрная.

Позиция — одна вертикальная сторона и одна горизонтальная.

- Вертикаль: `top` или `bottom`. Старт — `bottom: 15` (15 px).
- Горизонталь: `left` или `right`. Старт — `right: 5` (5 px).

Пустую сторону не пишут, и она не используется. Если в файле есть и `top`, и `bottom`, остаётся первая, вторая удаляется. То же для `left` и `right`. Первый ключ на оси задаёт отступ.

Если подпись включена, а файл шрифта не найден, этот ролик считается ошибкой. Если этот FFmpeg не умеет выбранный формат картинки, ролик тоже считается ошибкой.

Ролик, который не нарезали, кадра не получает.

## Команды

Флаги в команде подменяют профиль только на этот запуск. В файл они не пишутся.

```text
videosplitter -f movie.mp4
videosplitter -f ./videos --bulk
videosplitter -f ./videos --bulk --subfolders
videosplitter -f movie.mp4 -o D:\out
videosplitter -f movie.mp4 -p telegram
videosplitter -f movie.mp4 -p telegram --split-by size --split-size 100
videosplitter -f movie.mp4 --split-by fixed --split-minutes 10
videosplitter -f movie.mp4 --split-by flexible --min-length 5 --max-length 10
videosplitter -f movie.mp4 --split-by parts --split-parts 4
```

| Флаг | Смысл |
| --- | --- |
| `-f` | Один файл или папка, если рядом есть `--bulk` |
| `--bulk` | Источник — папка. Для папки обязателен. Ошибка, если `-f` — файл |
| `--subfolders`, `-sf` | Только вместе с `--bulk`. Искать и во вложенных папках и повторить этот относительный путь в папке вывода |
| `-o` | Папка вывода на этот запуск |
| `-p` | Имя профиля. Оно важнее `default_profile` |
| `--split-by` | `size`, `fixed`, `flexible` или `parts` |
| `--split-size` | Мегабайты, для `size` |
| `--split-minutes` | Минуты одной части, для `fixed` |
| `--min-length`, `--max-length` | Минуты, для `flexible` |
| `--split-parts` | Число частей, для `parts`. Минимум 1 |

`--bulk` без `--subfolders` смотрит только названную папку, без детей.

`--subfolders` без `--bulk` — неправильная команда.

С `--subfolders` файл `videos/trip/day1/clip.mp4` попадёт в `output/trip/day1/`. Папка `videos` — корень обхода, её в пути вывода нет.

## Мастер

`videosplitter` без `-f` открывает мастер. Он спрашивает то же, что задают флаги: файл или папку, обход и вложенные папки, профиль или числа нарезки, папку вывода. Планировщик тот же, что у команды. Ответы не записываются в YAML, если вы специально не правите настройки. Программа спрашивает по-английски, в таком порядке:

1. `Path: `
2. `Include subfolders? [y/n]: ` только если путь — папка
3. `Profile name (empty for default): `
4. `Override split mode? [y/n]: `
5. Если ответ `y`: `Split by [size/fixed/flexible/parts]: `, затем `MB: ` для size, `Minutes: ` для fixed, `Minimum minutes: ` и `Maximum minutes: ` для flexible, или `Parts: ` для parts
6. `Output directory (empty for settings): `

## Что происходит за один запуск

1. Читаются настройки. При первом запуске создаются файлы по умолчанию.
2. Читается профиль: `-p`, если он есть, иначе `default_profile`. Поверх накладываются флаги `--split-by`.
3. Собираются файлы. Один файл из `-f`, или папка для `--bulk`, плюс вложенные папки при `-sf`. Имена с чужим расширением пропускаются.
4. У каждого ролика длительность берётся из `ffprobe`, размер — из длины файла.
5. Планировщик возвращает части или ответ «не резать».
6. Если резать не нужно, для этого файла работа кончается. Файл остаётся на диске.
7. Для каждой части строится имя, `ffmpeg -c copy` пишет её во временную папку, затем файл переносится в вывод. Copy значит нарезку без нового кодирования.
8. Если замена выключена и такое имя уже есть, старый файл остаётся. Это не ошибка.
9. Если часть не удалась, этот ролик останавливается, временный файл удаляется, исходник не трогается.
10. Если все части этого ролика удались и хотя бы один новый файл записан, исходник удаляется только при включённой настройке.
11. Если кадры включены, картинка пишется после того, как файл части уже на месте. Сбой кадра валит ролик так же, как сбой части.

## Когда нарезки не будет

- Ролик короче минимальной длины части (1 минута, пока вы это не смените).
- Режим размера, и файл уже влезает в предел.
- Фиксированное время, и ролик влезает в один отрезок.
- Гибкое время, и ролик не длиннее максимума.
- Режим частей, и вы просили одну часть.
- Расширения нет в списке настроек. В папке такой файл просто пропускается.

Гибкое время ещё и падает с ошибкой, когда минимум и максимум нельзя выполнить вместе. Это не тихий пропуск.

## Слова

| Слово | Смысл |
| --- | --- |
| Профиль | YAML-файл с одним правилом нарезки, шаблоном имени и настройками кадра |
| Часть | Один временной кусок исходника |
| Планировщик | Кусок программы, который считает границы. FFmpeg он не вызывает |

| Bulk | Нарезать каждое подходящее видео в папке |
