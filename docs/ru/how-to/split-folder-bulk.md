# Нарезать все видео в папке

## Цель

Обработать все подходящие ролики в папке (и при необходимости во вложенных).

## Шаги

```text
videosplitter -f ./videos --bulk
videosplitter -f ./videos --bulk --subfolders
```

- `--bulk` обязателен, если `-f` — папка. Ошибка, если `-f` — файл.
- `--subfolders` / `-sf` только вместе с `--bulk`. Относительный путь повторяется в папке вывода.

Пример: с `--subfolders` файл `videos/trip/day1/clip.mp4` попадёт в `output/trip/day1/`. Корень обхода `videos` в пути вывода не повторяется.

`--bulk` без `--subfolders` смотрит только названную папку. Какие расширения считать видео — в [настройках](../reference/settings-yml.md).
