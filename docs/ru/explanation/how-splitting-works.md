# Как устроена нарезка

## Общая схема

1. Читаются настройки (при первом запуске создаются файлы по умолчанию).
2. Читается профиль (`-p` или `default_profile`), поверх — флаги `--split-by`.
3. Собираются файлы: один `-f` или папка для `--bulk`, плюс дети при `-sf`. Чужие расширения пропускаются.
4. У каждого ролика длительность из `ffprobe`, размер из файла.
5. **Планировщик** возвращает отрезки времени или «не резать». FFmpeg он не вызывает.
6. Если резать не нужно — файл остаётся.
7. Для каждой части: имя, запись `ffmpeg -c copy` во временную папку, перенос в вывод. **Копирование потока** — резка без нового кодирования.
8. Если замена выключена и имя занято — старый файл остаётся (не ошибка).
9. Сбой части: ролик останавливается, временный файл удаляется, исходник не трогается.
10. Успех всех частей и хотя бы один новый файл — исходник удаляется только при включённой настройке.
11. Кадры (если включены) пишутся после файла части; сбой кадра валит ролик.

## Когда нарезки не будет

- Ролик короче минимальной длины части (по умолчанию 1 минута)
- Режим размера и файл уже влезает в предел
- Фиксированное время и ролик влезает в один отрезок
- Гибкое время и ролик не длиннее максимума
- Режим частей с одной частью
- Расширения нет в списке настроек

Гибкое время ещё может **упасть с ошибкой**, если минимум и максимум нельзя выполнить вместе.

## Слова

| Слово | Смысл |
| --- | --- |
| Профиль | YAML с правилом нарезки, шаблоном имени и кадрами |
| Часть | Один временной кусок исходника |
| Планировщик | Считает границы; FFmpeg не вызывает |
| Копирование потока | FFmpeg `-c copy` без перекодирования |
| Bulk | Нарезать каждое подходящее видео в папке |
| `{source_dir}` | Папка источника в пути вывода |
