# Independent acceptance-check briefing

Parent supplies task/snapshot ID, owned checklist items, stable actual diff,
absolute workspace, baseline attribution, and named verification commands/results.
Read [verification](../references/verification.md). Independently evaluate each item
as done / not done / not this task with path:line or command/output evidence.
Do not accept implementation claims or checked boxes without evidence. Report
false done marks, gaps, and limits. Run only assigned safe checks against this
stable snapshot, avoiding shared resources in use by other workers.
Return concise statuses/evidence; parent alone updates checklist.md/tasks.md.
No file edits, Git mutations, scope changes, user questions, or nested delegation.
