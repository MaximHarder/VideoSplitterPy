# Final review briefing

Parent supplies focus (`Standards`, `Spec`, or `bug investigation`), stable snapshot
ID, start/end and uncommitted attributable diff, absolute workspace, source plan plus
accepted Adjustments, project standards, baseline limits, and relevant evidence.
Follow [verification](../references/verification.md). Read applicable review/investigation
skills for the assigned focus. Check only this completed snapshot and authorized scope.
Return compact findings: path:line, severity, problem, proposed fix, and evidence;
include snapshot ID and concrete verification limits, or no findings with limits.
No file edits, commits, approval changes, user questions, or recursive delegation.
Parent handles repairs and invalidates affected reviews after any changed snapshot.
